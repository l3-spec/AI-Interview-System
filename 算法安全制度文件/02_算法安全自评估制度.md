# 算法安全自评估制度

**文件编号**：YT-AI-002  
**版本**：V1.0 修订  
**生效日期**：2025年5月1日  
**制定单位**：杭州柚汀科技有限公司算法安全管理办公室  

---

## 第一章 总则

**第一条 制定目的**  
为规范本公司算法安全自评估工作，确保算法推荐服务安全合规，根据《互联网信息服务算法推荐管理规定》第十七条及相关要求，结合本公司实际情况，制定本制度。

**第二条 适用范围**  
本制度适用于本公司AI面试系统及相关算法推荐服务的自评估活动。

**第三条 评估原则**
1. **客观公正**：评估过程和结论客观真实，不弄虚作假；
2. **全面覆盖**：评估范围覆盖所有算法及其应用场景；
3. **预防为主**：及时发现和消除算法安全隐患；
4. **持续改进**：评估结果用于持续优化算法安全管理。

---

## 第二章 评估范围和周期

**第四条 评估范围**
1. AI面试系统的智能问题生成算法；
2. AI面试系统的候选人评估算法；
3. AI面试系统的语音驱动数字人算法；
4. 其他算法推荐服务及相关算法组件。

**第五条 评估周期**
1. **上线前评估**：新算法或算法重大变更上线前必须进行自评估；
2. **定期评估**：常规评估每年度至少进行一次；
3. **专项评估**：发生重大安全事件或法规要求变更时，须进行专项评估；
4. **复评**：整改完成后须进行复评。

---

## 第三章 评估内容

**第六条 算法设计文档审查**
1. 算法设计目的、功能范围、使用场景是否清晰明确；
2. 算法设计是否包含歧视性、偏见性内容；
3. 算法设计是否符合法律法规和国家标准要求；
4. 算法设计文档是否完整、规范。

**第七条 训练数据合规性检查**
1. 训练数据来源是否合法，是否存在非法获取数据的情况；
2. 训练数据是否包含侵犯用户隐私的内容；
3. 训练数据是否存在歧视性、偏见性内容；
4. 训练数据采集是否获得用户授权同意。

**第八条 算法安全性测试**
1. 算法是否存在已知安全漏洞；
2. 算法是否能够抵御恶意输入攻击；
3. 算法输出是否存在安全隐患；
4. 算法接口是否存在被恶意利用的风险。

**第九条 用户权益保护评估**
1. 算法是否充分尊重用户知情权；
2. 算法是否提供用户选择权和退出机制；
3. 算法是否保护用户个人信息安全；
4. 算法决策是否具有可解释性。

**第十条 算法日志审查**
1. 算法运行日志是否完整记录；
2. 日志内容是否包含敏感信息；
3. 日志存储是否安全；
4. 日志是否支持事后追溯和分析。

## 第四章 评估流程

**第十一条 评估流程**  
算法安全自评估工作按以下流程进行：

```
┌─────────────────────────────────────────────────────────────┐
│  步骤一：提交评估申请                                        │
│  由算法研发团队或产品团队向算法安全办提交评估申请            │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤二：组建评估小组                                        │
│  算法安全办根据评估对象组建评估小组，确定评估负责人          │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤三：制定评估方案                                        │
│  评估小组制定评估方案，明确评估范围、方式、时间安排          │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤四：实施评估                                            │
│  按照评估方案开展评估，收集证据材料，形成评估意见            │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤五：出具评估报告                                        │
│  评估小组出具评估报告，报告须包含评估结论和整改建议          │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤六：整改落实                                            │
│  被评估方根据评估报告进行整改，评估小组验证整改效果          │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  步骤七：归档备查                                            │
│  评估报告及相关材料归档保存，保存期限不少于3年                │
└─────────────────────────────────────────────────────────────┘
```

**第十二条 评估申请材料**  
评估申请须提交以下材料：
1. 算法安全自评估申请表；
2. 算法设计说明书；
3. 算法训练数据说明；
4. 算法功能说明书；
5. 用户权益保护措施说明；
6. 其他需要提交的材料。

**第十三条 评估报告内容**  
评估报告须包含以下内容：
1. 评估基本信息（评估对象、评估时间、评估人员等）；
2. 评估范围和方法；
3. 评估发现（合规项、不合规项、风险项）；
4. 评估结论；
5. 整改建议；
6. 附件（证据材料、测试记录等）。

## 第五章 责任分工

**第十四条 算法安全办职责**
1. 统筹管理公司算法安全自评估工作；
2. 制定和修订自评估制度和规范；
3. 组建和管理评估小组；
4. 审核评估报告和整改方案；
5. 监督评估工作的执行。

**第十五条 技术研发部职责**
1. 负责算法的具体自评估实施；
2. 配合评估小组开展评估工作；
3. 落实评估发现的问题整改；
4. 提交评估申请和相关材料。

**第十六条 法务合规部职责**
1. 负责算法合规性审查；
2. 审核评估结论是否符合法律法规要求；
3. 提供法律咨询和支持；
4. 协助处理合规性问题。

---

## 第六章 评估保障措施

**第十七条 制度执行保障**
1. 自评估报告须纳入算法变更审批流程，未通过评估的算法不得上线；
2. 评估记录保存期限不少于3年；
3. 定期对自评估制度本身进行评审和优化。

**第十八条 档案管理**
1. 评估档案须完整保存，包括评估申请表、评估报告、整改记录等；
2. 档案须建立索引，便于查询和使用；
3. 档案管理须遵守公司保密制度。

**第十九条 持续改进**
1. 评估发现的问题须纳入持续改进计划；
2. 定期分析评估数据，总结规律性问题；
3. 根据法律法规变化和业务发展，持续优化评估内容和标准。
