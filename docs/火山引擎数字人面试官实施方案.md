# 火山引擎数字人面试官实施方案

## 一、方案概述

本方案基于你现有的AI面试系统架构，整合火山引擎的豆包大模型、语音合成（TTS）、语音识别（ASR）能力，打造一个实时交互的数字人面试官。

### 现有系统基础
- ✅ 已有的AI面试流程和数据库设计
- ✅ Android端数字人界面（DUIX SDK）
- ✅ WebSocket实时通信架构
- ✅ DeepSeek大模型集成（可平滑迁移）

### 火山引擎优势
- 🎯 **豆包大模型**: 专业的对话能力，支持面试官角色扮演
- 🎙️ **语音合成**: 丰富的中文音色，支持情感控制
- 🎧 **语音识别**: 高准确率的中文语音转文字
- 🔄 **低延迟**: 端云结合，提供流畅的实时交互体验

### 3. 集成到现有流程

#### 更新 TTS 服务以支持火山引擎

编辑 `backend-api/src/services/ttsService.ts`，添加火山引擎支持：

```typescript
import { volcengineTtsService } from './volcengine';

// 在 checkTTSConfig() 中添加:
case 'volcengine':
  return !!process.env.VOLCENGINE_API_KEY;

// 在 textToSpeech() 的 switch 中添加:
case 'volcengine':
  result = await this.volcengineTTS(text, voice);
  break;

// 添加新方法:
private async volcengineTTS(text: string, voice?: string): Promise<TTSResult> {
  const result = await volcengineTtsService.synthesize({
    text,
    voice,
    saveToFile: true,
  });
  
  return {
    success: result.success,
    audioPath: result.audioPath,
    audioUrl: result.audioUrl,
    duration: result.duration,
    fileSize: result.fileSize,
    error: result.error,
  };
}
```

#### 创建火山引擎面试路由

创建 `backend-api/src/routes/volcengine-interview.ts`：

```typescript
import express from 'express';
import { volcengineRealtimeInterviewController } from '../services/volcengine/volcengineRealtimeInterviewController';

const router = express.Router();

// 开始面试
router.post('/start', async (req, res) => {
  try {
    const event = await volcengineRealtimeInterviewController.startInterview({
      sessionId: req.body.sessionId,
      userId: req.body.userId,
      jobPosition: req.body.jobPosition,
      jobCategory: req.body.jobCategory,
      userBackground: req.body.userBackground,
      companyName: req.body.companyName,
      totalQuestions: req.body.totalQuestions,
    });
    
    res.json(event);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// 处理用户输入
router.post('/chat', async (req, res) => {
  try {
    const event = await volcengineRealtimeInterviewController.processUserInput({
      sessionId: req.body.sessionId,
      userInput: req.body.userInput,
    });
    
    res.json(event);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// 结束会话
router.post('/end', (req, res) => {
  volcengineRealtimeInterviewController.endSession(req.body.sessionId);
  res.json({ success: true });
});

export default router;
```

## 五、面试流程设计

### 完整的实时交互流程

```
1. 用户点击"开始面试"
   ↓
2. 前端建立WebSocket连接 / 创建会话
   ↓
3. 后端调用豆包大模型生成开场白
   ↓
4. 后端调用火山引擎TTS合成语音
   ↓
5. 前端接收文本+语音，播放语音并驱动数字人
   ↓
6. 用户语音回答，本地ASR转文字
   ↓
7. 前端发送文本到后端
   ↓
8. 后端保存回答，生成下一题/分析
   ↓
9. 重复步骤3-8，直到面试完成
   ↓
10. 生成结束语和面试报告
```

### 面试状态机

```
PREPARING
    ↓
IN_PROGRESS (开场白)
    ↓
WAITING_FOR_ANSWER (等待用户回答)
    ↓
IN_PROGRESS (生成下一题/追问)
    ↓
WAITING_FOR_ANSWER
    ↓ (循环)
COMPLETED (生成结束语)
```

## 六、关键优化点

### 1. 降低延迟 - 本地优先策略

| 操作 | 现有方案 | 优化方案 | 效果 |
|------|----------|----------|------|
| ASR语音识别 | 服务端 | 端侧本地ASR | ⚡ 延迟降低80% |
| TTS语音合成 | 服务端预生成 | 流式TTS + 缓存 | ⚡ 首字延迟<500ms |
| 数字人渲染 | 服务端视频 | 端侧实时驱动 | ⚡ 无延迟，省带宽 |

## 八、迁移指南

### 从 DeepSeek 迁移到豆包

1. **配置切换**：设置环境变量 `LLM_PROVIDER=volcengine`
2. **API兼容**：豆包API兼容OpenAI格式，可平滑迁移
3. **提示词优化**：豆包对中文理解更好，可优化中文提示词

### 从 Azure/阿里云 TTS 迁移到火山引擎

1. **配置切换**：设置 `TTS_PROVIDER=volcengine`
2. **音色映射**：
   - Azure zh-CN-XiaoxiaoNeural → volcengine zh_female_qingxin
   - 阿里云 siqi → volcengine zh_female_zhiyin
